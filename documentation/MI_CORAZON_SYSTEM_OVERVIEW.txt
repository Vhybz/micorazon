2. CORE PURPOSE
---------------
Mi~Corazon is an end-to-end management system for a butchery enterprise.
It automates the entire meat lifecycle: from slaughterhouse logging and
carcass breakdown (yield math) to production floor processing,
barcode label printing, and a high-speed Point-of-Sale (POS) with
integrated bank deposit verification and GRA-compliant financial reporting.


3. TECHNICAL STACK
------------------
* Frontend: Flutter (SDK ^3.11.5)
* State Management: flutter_riverpod (using riverpod_generator)
* Backend: Supabase (Postgres, Realtime, Auth, Storage)
* Local Data/Offline: Hive (Sync Queue), Drift (SQLite persistence)
* Hardware: printing & pdf packages (Thermal labels/Receipts)
* Notifications: Arkesel SMS Gateway Integration


4. VALIDATION FOCUS (PRIORITY REVIEW AREAS)
-------------------------------------------
* Offline-First Sync Engine (lib/services/offline_sync_service.dart):

* Butcher Workflow (lib/screens/butcher/):
  - Carcass Breakdown Station: Math logic verification for live-to-meat
    weight conversion and yield tracking.
  - State Lock Logic: Verification of _statusOverrides in
    SlaughterLogNotifier to prevent UI flickering during background sync.

* UI Resilience:
  Validation of the Meat Processing screen's unified scrolling
  architecture to ensure stable rendering on all mobile device sizes.


5. DATABASE ARCHITECTURE (Key Entities)
---------------------------------------
* slaughter_logs: Farm-to-carcass traceability.
* meat_batches: Production floor dissection tracking.
* sales: Complex transaction storage using JSONB.
* stock_transfers: Production-to-Sales movement auditing.
